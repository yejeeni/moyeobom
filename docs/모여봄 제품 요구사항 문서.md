# 모여봄 제품 요구사항 문서

Oct 5, 2026 · @예진

## 개요

이 문서는 모여봄 1단계(혼자 쓰는 가상 열람실, 비회원)의 요구사항을 개발 가능한 수준으로 정의하고, 2·3단계는 방향만 적는다.

### 범위

| 단계 | 다루는 수준 | 내용 |
| --- | --- | --- |
| 1단계 | 상세 | 비회원 식별, 스프린트와 할 일, 뽀모도로 타이머, 가상 열람실, 회고와 이월, 내 캐릭터 이미지 |
| 2단계 | 개요 | 실제 유저 실시간 접속, 자리 이어받기, 다중 열람실 |
| 3단계 | 개요 | 회원, 방 만들기와 초대, 기록 모아보기, 저자극 모드 |

### 용어

| 용어 | 뜻 |
| --- | --- |
| 게스트 | 회원 가입 없이 브라우저에 저장된 고유 ID로 식별되는 사용자 |
| 스프린트 | 계획을 세우면 시작되고 "오늘 마무리"를 누르면 끝나는 할 일 묶음. 게스트당 열린 스프린트는 하나 |
| 할 일 | 스프린트에 속한 작업. 예상 시간은 선택 입력 |
| 집중 세션 | 할 일 하나에 대해 타이머를 시작해서 끝날 때까지의 기록 |
| 열람실 | 9개 자리로 이루어진 공부 공간 화면 |
| 가상 메이트 | 서버가 만들어 빈자리를 채우는 가상 유저 |

## 사용자 스토리

1단계는 아래 8개 스토리를 모두 만족해야 완료로 본다.

| ID | 나는 | 원하는 것 | 이유 |
| --- | --- | --- | --- |
| US-01 | 처음 온 사용자로서 | 가입 없이 바로 쓰고 싶다 | 시작 장벽이 낮아야 써보기 때문에 |
| US-02 | 사용자로서 | 오늘 할 일을 적고 입장하고 싶다 | 무엇을 할지 정해야 시작할 수 있어서 |
| US-03 | 사용자로서 | 혼자 접속해도 북적이는 열람실을 보고 싶다 | 누군가 함께 있다는 느낌이 집중을 돕기 때문에 |
| US-04 | 사용자로서 | 할 일을 골라 타이머를 시작하고 싶다 | 집중한 시간이 그 일에 쌓이게 하려고 |
| US-05 | 사용자로서 | 내 집중·휴식 상태가 내 자리에 보이길 원한다 | 열람실의 일원이라고 느끼고 싶어서 |
| US-06 | 사용자로서 | 하루를 마치고 예상과 실제 시간을 비교하고 싶다 | 내 시간 감각을 알고 싶어서 |
| US-07 | 사용자로서 | 못 끝낸 일을 다음 스프린트로 넘길지 정하고 싶다 | 다시 적는 수고를 덜고 싶어서 |
| US-08 | 사용자로서 | 가상 메이트가 있다는 걸 알고 싶다 | 속았다고 느끼지 않기 위해 |

## 기능 요구사항: 스프린트와 할 일

입장 전에 할 일이 최소 1개 있어야 하며, 게스트는 동시에 하나의 스프린트만 열 수 있다.

| ID | 요구사항 | 수용 기준 |
| --- | --- | --- |
| FR-G01 | 첫 접속 시 게스트 ID를 발급해 브라우저에 저장한다 | 새로고침하거나 다시 접속해도 같은 게스트로 인식된다 |
| FR-S01 | 열린 스프린트가 없으면 계획 화면을 보여준다 | 계획 화면에서 할 일을 추가하면 스프린트가 생성된다 |
| FR-S02 | 열린 스프린트가 있으면 이어서 진행한다 | 다시 접속하면 기존 할 일과 기록이 그대로 보인다 |
| FR-S03 | 할 일이 0개면 열람실 입장 버튼을 비활성화한다 | 할 일을 1개 추가하는 순간 입장 버튼이 활성화된다 |
| FR-T01 | 할 일을 추가, 수정, 삭제할 수 있다 | 제목은 필수, 공백만 있는 제목은 저장되지 않는다 |
| FR-T02 | 예상 시간은 분 단위로 선택 입력한다 | 비워두면 저장되고, 회고 비교에서 제외 표시된다 |
| FR-T03 | 열람실 안에서도 할 일을 추가할 수 있다 | 추가한 할 일이 바로 목록과 남은 일 수에 반영된다 |
| FR-T04 | 할 일을 완료 처리할 수 있다 | 완료 시 그 할 일의 실제 시간이 확정되고 완료한 일 수가 늘어나며, 리프레시 문구 하나를 무작위로 보여준다 |
| FR-T05 | 집중 기록이 있는 할 일은 삭제 대신 닫기만 가능하다 | 기록이 있는 할 일의 삭제 버튼이 보이지 않는다 |

## 기능 요구사항: 타이머와 집중 세션

타이머는 할 일 앞에서 시작해 시간이 올라가는 스톱워치 방식이며, 뽀모도로처럼 정해진 시간으로 끊지 않는다.

| ID | 요구사항 | 수용 기준 |
| --- | --- | --- |
| FR-F01 | 할 일 앞에서 집중을 시작한다 | 타이머가 0부터 올라가고, 내 자리가 집중 상태로 바뀐다 |
| FR-F02 | 집중 세션은 동시에 하나만 진행된다 | 다른 할 일의 집중을 시작하면 진행 중인 세션이 먼저 종료·기록된다 |
| FR-F03 | 일시정지 없이 중단만 할 수 있다 | 중단하면 그때까지의 시간이 해당 할 일에 기록된다 |
| FR-F04 | 집중 중 할 일을 완료하면 세션을 종료한다 | 세션이 기록되고, 다음 할 일을 고르는 대기 상태가 된다 |
| FR-F05 | 휴식 버튼으로 휴식 상태로 바꿀 수 있다 | 진행 중인 세션이 기록되고, 내 자리 스탠드가 꺼지며 휴식 경과 시간이 표시된다 |
| FR-F06 | 휴식은 할 일을 골라 집중을 시작하면 끝난다 | 휴식 시간은 할 일 기록에 포함되지 않는다 |
| FR-F07 | 1분 미만 세션은 저장하지 않는다 | 60초 미만으로 끝난 세션은 실제 시간에 더해지지 않는다 |
| FR-F08 | 세션 시작·종료 시각은 서버 시각으로 기록한다 | 사용자 PC 시계를 바꿔도 기록된 시간이 달라지지 않는다 |
| FR-F09 | 연결이 끊기면 세션을 자동 종료한다 | 연결 확인 신호를 10초마다 주고받고, 30초 동안 신호가 없으면 마지막 신호 시각을 종료 시각으로 기록한다 |
| FR-F10 | 휴식 알림은 선택 옵션이다 | 기본은 꺼짐. 켜면 설정한 시간(기본 50분)만큼 집중했을 때 리프레시 문구와 함께 한 번 알린다 |

## 기능 요구사항: 열람실과 가상 메이트

1단계 열람실은 게스트마다 따로 만들어지며, 인원(나 포함 1~9명, 기본 9명)만큼 자리가 생기고 나와 가상 메이트가 앉아 있다. 처음에 빈 자리는 시간이 지나며 새 메이트가 들어와 채운다.

| ID | 요구사항 | 수용 기준 |
| --- | --- | --- |
| FR-R01 | 입장하면 열람실 자리 중 하나에 배정된다 | 내 자리는 "나"로 표시되고 테두리로 강조된다 |
| FR-R15 | 열람실 인원을 1~9명 중에서 고를 수 있다 | 기본은 9명이다. 첫 화면과 열람실 설정에서 고르고 브라우저에 기억한다. 열람실에서 바꾸면 그 인원의 새 열람실로 옮긴다(할 일과 기록은 그대로). 인원에 따라 칸 배치와 크기가 화면에 맞게 바뀐다 |
| FR-R02 | 모든 자리는 같은 규칙으로 캐릭터와 닉네임을 받는다 | 캐릭터는 캐릭터 목록에서 자리마다 무작위로 배정된 그림(FR-R14), 닉네임은 형용사 30개와 명사 30개의 조합(900가지)이며 중복을 허용한다 |
| FR-R03 | 닉네임은 입장할 때 정해지고 그 열람실에 있는 동안 유지된다 | 다시 입장하면 새 닉네임을 받는다 |
| FR-R04 | 각 자리에 상태 정보를 표시한다 | 닉네임, 집중 또는 휴식과 경과 시간, 완료한 일 수와 남은 일 수 |
| FR-R05 | 가상 메이트는 집중, 휴식, 퇴장 상태를 오간다 | 상태 변화는 서버가 정하고 WebSocket 이벤트로 전달된다 |
| FR-R06 | 가상 메이트의 행동은 기계적으로 보이지 않아야 한다 | 처음 인원은 방마다 무작위(나 포함 5\~9명)다. 집중은 25\~90분, 휴식은 5\~15분 범위에서 무작위로 정하고, 항상 자리에 앉은 사람의 과반은 집중 상태다. 범위는 설정값으로 바꿀 수 있다 |
| FR-R07 | 가상 메이트도 할 일 수를 가진다 | 집중을 마칠 때 일부 확률로 완료한 일 수가 늘어난다 |
| FR-R08 | 퇴장한 자리는 잠시 비었다가 새 메이트로 채워진다 | 새 메이트는 새 캐릭터와 닉네임을 받는다 |
| FR-R09 | 입장과 퇴장은 짧은 알림으로 보여준다 | "졸린 수달님이 들어왔어요" 형식으로 몇 초 뒤 사라진다 |
| FR-R10 | 내 상태 변화는 내 자리에 즉시 반영된다 | 집중 시작, 휴식, 완료가 1초 안에 화면에 보인다 |
| FR-R11 | 가상 메이트가 섞여 있다는 사실을 안내한다 | 첫 화면과 열람실 안내 버튼에서 확인할 수 있다. 개별 자리가 가상인지는 표시하지 않는다 |
| FR-R12 | 창 폭이 좁으면 컴팩트 모드로 바뀐다 | 다른 프로그램 옆에 띄운 좁은 창에서도 9개 자리와 내 타이머가 보인다 |
| FR-R13 | 사용자가 캐릭터 그림을 직접 등록할 수 있다 | 캐릭터 폴더(상태별 그림 2장씩 6장, 선택으로 배경 1장)를 가져오면 이 브라우저에만 저장되고 서버로는 보내지 않는다. 그림 일부가 빠지면 다른 그림으로 대신한다 |
| FR-R14 | 열람실 자리마다 캐릭터를 무작위로 배정한다 | 기본 캐릭터와 내 캐릭터 중에서 뽑고, 같은 방에서는 새로고침해도 같은 모습이다. 중복 허용 여부, 기본 캐릭터 포함 여부, 내 자리 고정 캐릭터를 고를 수 있다 |

## 기능 요구사항: 회고와 이월

사용자가 "오늘 마무리"를 누를 때만 스프린트가 끝나며, 자동 정산은 하지 않는다.

| ID | 요구사항 | 수용 기준 |
| --- | --- | --- |
| FR-C01 | 오늘 마무리를 누르면 회고 화면으로 이동한다 | 진행 중인 집중 세션이 있으면 먼저 종료·기록된다 |
| FR-C02 | 할 일별 예상 시간과 실제 시간을 비교한다 | 차이를 분 단위로 보여준다. 예상 시간이 없는 할 일은 "예상 없음"으로 표시하고 비교에서 뺀다 |
| FR-C03 | 스프린트 요약을 보여준다 | 총 집중 시간, 완료한 일 수, 예상이 있는 완료 할 일 기준 예상 합계 대비 실제 합계 |
| FR-C04 | 못 끝낸 할 일마다 이월 또는 닫기를 고른다 | 기본 선택은 이월이다 |
| FR-C05 | 회고를 확정하면 스프린트가 닫힌다 | 닫힌 스프린트의 기록은 수정할 수 없다 |
| FR-C06 | 확정 전에는 열람실로 돌아갈 수 있다 | 돌아가면 스프린트는 열린 상태 그대로다 |
| FR-C07 | 이월한 할 일은 다음 계획 화면에 미리 채워진다 | 제목이 복사되고 남은 작업 기준으로 예상 시간을 다시 입력한다. 실제 시간은 새 스프린트에서 0부터 재고, 할 일 상세에서는 이전 스프린트를 포함한 누적 시간도 보여준다 |

## 상태 정의

내 상태는 버튼으로만 바뀌고, 가상 메이트의 상태는 서버가 정한 지속 시간에 따라 바뀐다.

가상 메이트는 휴식 중에만 퇴장하며, 퇴장한 자리는 잠시 비었다가 새 메이트가 입장해 집중 상태로 시작한다.

## 비기능 요구사항

1단계는 Oracle Cloud 무료 인스턴스 한 대에서 동작하는 것을 전제로 한다.

| ID | 분류 | 요구사항 |
| --- | --- | --- |
| NFR-01 | 응답성 | 상태 변화 이벤트는 발생 후 1초 안에 화면에 반영된다 |
| NFR-02 | 응답성 | 회고 화면은 1초 안에 표시된다 |
| NFR-03 | 신뢰성 | 연결이 끊기거나 브라우저를 닫아도 집중 세션 기록이 사라지지 않는다 |
| NFR-04 | 신뢰성 | 서버가 재시작되면 가상 메이트는 새로 만들어져도 되지만, 스프린트·할 일·세션 기록은 유지된다 |
| NFR-05 | 보안 | 게스트 ID는 추측할 수 없는 UUID를 쓰고, 다른 게스트의 기록에 접근할 수 없다 |
| NFR-06 | 보안 | 할 일 제목 등 사용자 입력은 서버에서 검증하고 화면 출력 시 스크립트로 실행되지 않는다 |
| NFR-07 | 개인정보 | 1단계는 이름, 이메일 등 개인정보를 수집하지 않는다 |
| NFR-08 | 호환성 | PC용 최신 Chrome, Edge, Safari, Firefox에서 동작한다 |
| NFR-09 | 접근성 | 운영체제의 "동작 줄이기" 설정을 따르고, 상태는 색과 함께 글자로도 표시한다 |
| NFR-10 | 개발 | 모든 API는 Swagger 문서로 제공하고, 프론트엔드는 이 문서를 기준으로 만든다 |
| NFR-11 | 운영 | DB는 정기적으로 백업하고, 서버 오류는 로그로 남긴다 |

## 제외 범위와 결정 사항

1단계에서는 아래 기능을 만들지 않으며, 사용자 간 채팅이나 응원 같은 상호작용은 전 단계에서 제외한다.

### 1단계 제외 범위

- 회원 가입과 로그인
- 실제 유저끼리 같은 열람실에 접속하는 기능
- 방 만들기와 초대
- 지난 스프린트 기록 모아보기
- 모바일 화면 최적화

### 이후 단계 방향

- **2단계**: 실제 유저가 WebSocket으로 같은 열람실에 접속한다. 실제 유저가 들어오면 가상 메이트가 자연스럽게 퇴장하고 그 자리를 이어받으며, 방이 차면 새 열람실을 연다.
- **3단계**: 회원 기능과 비회원 기록 이전, 방 만들기와 초대 링크, 스프린트 기록 모아보기, 저자극 모드를 추가한다.

### 결정 사항

| 항목 | 결정 |
| --- | --- |
| 가상 메이트 지속 시간 | 집중 25\~90분, 휴식 5\~15분에서 무작위. 휴식 중 퇴장 확률 20%. 모두 설정값으로 조정 가능한 초기값 |
| 가상 메이트 처음 인원 | 메이트 4\~8명에서 무작위. 빈 자리는 1\~15분 사이에 새 메이트가 들어와 채운다. 설정값으로 조정 가능 |
| 연결 확인 | STOMP 연결 확인 신호를 10초 주기로 주고받고, 30초 무응답이면 끊김으로 판단 |
| 이월한 할 일 | 남은 작업 기준으로 다시 추정. 회고는 해당 스프린트 시간만 비교하고, 누적 시간은 할 일 상세에서 표시 |
